செலுத்துதல் & விவரம் அனுப்புதல் - அமைப்பு (ஒருமுறை மட்டும்)
===========================================================

1) Google Sheet-ல் புதிய tab சேர்க்கவும். பெயர் சரியாக இப்படி இருக்க வேண்டும்:   செலுத்துதல்

2) முதல் வரிசையில் தலைப்புகள் (Headings):
      A: தலைப்பு      B: இமெயில் ID      C: UPI ID      D: காட்டு      E: செல் எண்

3) 2-ஆம் வரிசையிலிருந்து ஒவ்வொரு வரிசைக்கும்:
      A = ஆப்பில் தெரியும் தலைப்பு
      B = விவரம் அனுப்ப வேண்டிய இமெயில் ID
      C = பணம் செலுத்த வேண்டிய UPI ID (எ.கா. name@oksbi)
      D = காலியாக விடவும் (காட்டும்). மறைக்க வேண்டுமானால் "இல்லை" என்று எழுதவும்.
      E = அழைக்க வேண்டிய செல் எண் (எ.கா. 9876543210). காலியாக விட்டால் 📞 பொத்தான் வராது.
   வரிசை வரிசைப்படியே ஆப்பிலும் தெரியும். இமெயில் அல்லது UPI ஏதாவது ஒன்று காலியாக இருந்தால், அதற்கான பொத்தான் மட்டும் வராது.

4) Apps Script:
   a) apps-script/Code.gs-ன் முழு உள்ளடக்கத்தையும் Apps Script-ல் ஒட்டி Save செய்யவும்.
   b) Deploy > Manage deployments > (பென்சில்) > Version: New version > Deploy.
   c) (விருப்பம்) மேலே function பட்டியலில் testPay-ஐத் தேர்ந்து ▶ Run செய்து, Execution log-ல் உங்கள் வரிசைகள் தெரிகிறதா என்று பார்க்கலாம்.

5) Sheet-ல் மாற்றியது ஆப்பில் தெரிய சுமார் 5 நிமிடம் ஆகும்.
